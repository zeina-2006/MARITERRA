01 / FUNDAMENTAL CONCEPT

What Is Machine Learning?

Machine Learning (ML) is a branch of Artificial Intelligence that enables computer systems to identify patterns in data and use those patterns to make predictions or decisions.

Instead of writing a separate rule for every possible situation, developers provide a learning algorithm with relevant data. The algorithm adjusts its internal parameters during training to capture relationships in that data.

After training, the resulting model can process new inputs and generate outputs. Its performance depends on the quality of its data, the suitability of its algorithm, and how well it generalizes to situations it has not previously encountered.

Learning from Data

Models identify useful relationships within examples rather than relying only on manually written rules.

Pattern Recognition

Algorithms discover trends, similarities, and unusual behavior in complex datasets.

Prediction and Generalization

A trained model applies learned patterns to new data, although predictions remain subject to uncertainty.

02 / UNDERSTANDING THE RELATIONSHIP

AI, Machine Learning & Deep Learning.

These terms are related, but they do not describe exactly the same technology. Understanding their relationship is essential before studying advanced intelligent systems.

AI Artificial Intelligence
The broad field of intelligent systems.
ML Machine Learning
A subset of Artificial Intelligence.
DL Deep Learning
A specialized subset of Machine Learning using multi-layer neural networks.

Relationship: Deep Learning is part of Machine Learning, and Machine Learning is part of Artificial Intelligence. Not every AI system uses machine learning, and not every ML model uses deep neural networks.

03 / CORE LEARNING PARADIGMS

Three Ways Machines Learn.

Machine learning methods are commonly organized into three major paradigms. Each approach uses a different source of information or feedback.

PARADIGM 01
◎

Supervised Learning

The model learns from labeled examples. Each training example contains input data and a known target output. During training, the model compares its prediction with the correct answer and adjusts its parameters.

MARITIME EXAMPLE Predicting engine condition using historical sensor measurements labeled as normal or faulty.
PARADIGM 02
⌘

Unsupervised Learning

The model analyzes data without predefined target labels. It attempts to discover hidden structures, clusters, similarities, or unusual observations.

MARITIME EXAMPLE Grouping vessels according to operating patterns or identifying unusual fuel consumption behavior.
PARADIGM 03
↗

Reinforcement Learning

An agent interacts with an environment, takes actions, and receives rewards or penalties. It learns a policy that aims to maximize cumulative reward over time.

MARITIME EXAMPLE Researching route or control strategies in a simulated maritime environment under safety constraints.

Building a useful ML model is a structured engineering process. Training is only one part of the complete workflow.

STEP 01

STEP 02

STEP 03

STEP 04

Test the model using unseen data and suitable performance metrics.

STEP 05

Integrate the model into a system and monitor its performance over time.

05 / IMPORTANT ALGORITHMS

Algorithms Behind Machine Learning.

Different algorithms are designed for different types of problems. Selecting an algorithm requires understanding the available data, target outcome, operating constraints, and acceptable error.

Linear Regression

Estimates a continuous numerical value by modeling relationships between input features and an output variable. It can be used as a baseline for fuel-consumption estimation.

Logistic Regression

Estimates class probabilities, often for binary classification tasks such as predicting whether an observation belongs to a particular risk category.

Decision Trees

Split data through a sequence of feature-based decisions. Their structure can be easier to interpret than many complex models.

Random Forest

Combines predictions from multiple decision trees. It can improve predictive stability and handle various structured-data problems.

Support Vector Machines

Identify decision boundaries that separate classes. Kernel methods can model nonlinear relationships in suitable datasets.

K-Means Clustering

Groups observations into clusters based on their similarity to cluster centers. It is a common unsupervised learning method.

Neural Networks

Use connected computational units arranged in layers to learn complex relationships. They are useful for many advanced data tasks.

Reinforcement Learning Algorithms

Methods such as Q-learning help an agent learn action strategies through interaction with an environment and reward feedback.

09 / ENGINEERING LIMITATIONS

What Machine Learning Cannot Guarantee.

ML systems can provide valuable analytical support, but their predictions are not automatically accurate, reliable, or suitable for every operational situation.

Data Quality Problems

Missing measurements, incorrect labels, sensor errors, and inconsistent records can reduce model reliability.

Overfitting

A model may memorize training examples and perform poorly when it encounters new operating conditions.

Data Bias

Training data that does not represent the real operational environment may produce systematically unreliable results.

Model Drift

Changes in equipment, operating practices, weather, or data distributions can reduce performance after deployment.

Limited Explainability

Some complex models provide predictions that are difficult for operators to interpret and independently verify.

Safety and Cybersecurity

Model outputs can be affected by manipulated data, compromised systems, or unsafe integration with operational technology.
